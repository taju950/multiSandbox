#text# This file is about explaining how to use the ***"Mark Down"*** file

## For Heading use syntax as below:
```md
# markdown #
## learning ##
#  This is a H1 header
## This is a H2 header
### This is a H3 header
#### This is a H4 header
##### This is a H5 header
###### This is a H6 header 
```

## for emphasis use syntax below:
```md
*This text will be italic*  
**This text will be bold**  
***This text will be bold and italic***
```
## for use of block code ##
```md
> This is a blockquote.
> It can span multiple lines.
```
## for use of code blocks ##
```md
Inline code can be formatted using backticks, while multiline code blocks can be created using triple backticks.

Here is some `inline code`.
```
